# FLUX 3.3.23

修复 3.3.22 引入的页面切换问题：点击左侧导航后，旧页面的标题区没有移除，每切换一次页面就在顶部多叠一层“分组 / 标题 / 描述”。

- 页面标题区与路由内容区原先使用了相同的 React key，切换路由时旧标题无法卸载。现在两者使用各自独立的 key，每个页面只保留一个标题区，标题的进场动画不受影响。

## 升级说明

本次只涉及前端，升级面板即可，Agent 无需升级，接口与数据无变化。

## 验证

前端 TypeScript、生产构建和 ESLint 检查通过。在无头浏览器中依次点击全部 11 个侧栏页面：修复前标题区数量从 1 累积到 11，并出现重复 key 警告；修复后每个页面始终只有一个标题区，警告消失。发布流水线继续验证两种 Linux 架构的镜像、自升级和失败恢复。
