# FLUX 3.3.29

控制台界面重绘，并修复开启 GitHub 加速后“检查更新”失败的问题。

## 界面重绘

视觉语言参考 [WAOR/Monitor-SAO](https://github.com/WAOR/Monitor-SAO)（MIT）的元素设计，只借鉴样式，未引入其代码。页面功能和操作流程不变。

- **托盘与卡片**：侧栏和页面内容各是一块圆角托盘，上下齐平；卡片浮在托盘上。浅色为浅灰底白卡片，深色为纯黑底深灰卡片。
- **桌面端取消顶栏**：搜索（⌘K）、账号菜单、深浅色切换和侧栏收起按钮都移到侧栏里。页面内容在右侧托盘内滚动，整页不再滚动。手机端保留顶栏和整页滚动。
- **页面标题**：每页顶部是胶囊标签加大标题；仪表盘标题改为按时段变化的问候语。
- **组件**：指标卡、带描边的彩色标签、全圆角状态胶囊、分段方块进度条、带描边的图标块。
- **配色与字体**：中性灰改为无色偏的灰阶；默认蓝及成功、警告、危险色换成同一套色板，强调色仍可在“系统设置 → 外观”切换。西文和数字使用随包自托管的 Geist / Geist Mono，不依赖外部字体 CDN。
- **登录页**与修改密码页改为同样的托盘布局。

## 修复

- **检查更新**：开启 GitHub 加速后，“检查更新”会超时或返回 403。加速镜像只转发 `github.com` 的下载，不支持 `api.github.com`。现在查询版本直接访问 GitHub API，加速只用于下载发布文件，与节点升级的做法一致。
- **标签页图标**：`favicon.ico` 之前没有被打进生产构建，`/favicon.ico` 返回 404。现已随构建发布，并换成与侧栏品牌标一致的图标。在“站点品牌”里上传过自定义图标的面板不受影响。

## 已知差异

- 桌面端页面向下滚动后，不再有顶栏显示当前页面名，当前页面看侧栏高亮项。
- 安装为桌面/手机应用时的图标（PWA）未更换，仍是旧图。

## 升级说明

只涉及面板，**Agent 无需升级**。可直接使用面板自升级。升级后如果界面样式或标签页图标仍是旧的，强制刷新一次浏览器（Ctrl+Shift+R）。

## 验证

前端 TypeScript、生产构建和 ESLint 通过。全部 11 个页面及登录页在桌面/手机、浅色/深色下用模拟数据截图检查，无控制台报错；另在连接演示数据库的本地面板上验证了登录、页面内滚动、设置页分区导航、账号菜单和 ⌘K 搜索。“检查更新”的修复带有后端回归测试。
