# FLUX 3.3.13

重做登录页、首次改密页，并打磨应用外壳。

- 登录页左侧介绍区改为带点阵与强调色光晕的面板，链路示意（入口节点 → 转发隧道 → 目标服务）带流动动画（系统开启“减少动态效果”时自动关闭），三项能力说明改为图标 + 标题 + 描述。
- 登录卡片去掉多余图标，用户名、密码输入框带前置图标；启用通行证密钥时以“或”分隔两种登录方式；顶部栏改为透明悬浮，不再占用一整条白色区域。
- 首次登录强制改密页与登录页统一卡片样式：警示图标、更清晰的说明、带图标的输入框、提示文字，并新增“退出登录”入口。
- 侧栏当前页面使用强调色高亮，悬停有底色反馈；侧栏底部版本信息更紧凑。
- 右上角账号菜单顶部显示头像、用户名与角色，管理员可直接进入系统设置。
- 快速访问（⌘K）结果显示页面说明，支持方向键选择、回车打开；使用输入法选字时按回车不会误跳转。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端在浏览器中检查登录页（含通行证密钥按钮）、改密页表单校验、账号菜单、快速访问键盘操作与手机端导航抽屉，覆盖浅色与深色模式、1440 宽度与手机宽度。
