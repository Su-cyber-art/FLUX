# FLUX 3.3.14

整理主要编辑弹窗的表单结构。

- 新增统一的表单分区样式：每组字段带小标题与说明，分区之间以细线分隔。
- 转发规则弹窗分为“基本信息 / 入口 / 目标 / 高级设置”：名称与隧道、入口端口与监听 IP 两两并排；弹窗宽度从 1000px 收窄到 800px。
- 用户弹窗分为“账号 / 配额与限制 / 有效期与状态”，标题下补充说明；提交按钮按场景显示“创建用户”或“保存修改”；配额状态卡片改用语义色。
- 节点弹窗分为“基本信息 / 续费 / 连接地址 / 运行模式”：续费周期与基准时间并排，续费示例并入字段说明，去掉单独的提示条；弹窗宽度收窄到 800px。
- 隧道弹窗：名称与类型并排，“入口配置 / 转发链配置 / 出口配置”标题与其他弹窗分区标题统一字号；编辑时不再重复显示“无法修改隧道类型”。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端在浏览器中打开新增 / 编辑转发规则、用户、节点、隧道弹窗检查分区与字段对齐，并核对用户弹窗中全部字段和配额重置按钮均保留。
