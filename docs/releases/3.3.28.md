# FLUX 3.3.28

同步上游 FLVX 3.0.1-rc12。修复 SQLite 面板从旧版本升级后无法新建隧道的问题，同时修正监控页的实时状态。

## SQLite 升级修复

- **受影响范围**：使用 SQLite、从 3.3.25 或更早版本升级到 3.3.26 / 3.3.27 的面板。升级时没有给 `tunnel` 表补上 `relay_auth_mode` 列，新建隧道会报错 `table tunnel has no column named relay_auth_mode`，开启 relay 认证也会失败。PostgreSQL 面板和全新安装不受影响。
- **修复方式**：面板启动时自动补上该列。已有隧道统一按 `legacy` 模式处理，与 3.3.26 的升级说明一致。补列可重复执行，不会把已启用认证的隧道降级。升级到本版本即可，无需手动操作。

## 监控页

- 监控页只建立一条节点实时连接。之前节点视图会再单独打开一条，同一节点的在线状态分两处维护，可能互相不一致。
- 定时刷新节点列表时，较早发出的请求不再覆盖更新的结果。请求进行期间收到的实时状态优先于刷新返回的快照。

## 未合入

上游 3.0.1-rc11 重写了其 Docker Compose 自升级流程。FLUX 使用自己的面板自升级实现，已经涵盖其中的保护措施（沿用原 Compose 项目和宿主机路径、镜像校验通过后才替换配置、升级任务状态持久化、失败时回滚），因此未合入该部分。

## 升级说明

只涉及面板，**Agent 无需升级**。可直接使用面板自升级。

## 验证

本地后端完整测试（含上游新增的 SQLite 升级迁移回归测试）、`go vet`，以及前端 TypeScript、生产构建和 ESLint 均通过。另用 3.3.27 的代码复现了新建隧道失败的问题，本版本中该场景通过。
