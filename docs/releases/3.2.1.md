# FLUX 3.2.1

统一修复 iOS 和其他手机上的弹窗位置、滚动与操作区域，打磨诊断和表单细节。

- 修复弹窗内容样式误作用于定位容器的问题，移除各页面重复的宽度覆盖与移动端自动全屏。诊断、编辑、权限管理、搜索和升级进度统一居中，保留屏幕安全区。
- 弹窗高度跟随可见视口，适应横竖屏切换和键盘占用空间；长内容在正文内部滚动，标题、关闭按钮及底部操作保持可见。
- 规则与隧道诊断共用结果布局，清晰展示入口、中继和出口测试；支持长名称、IPv6、等待状态与失败详情，也会显示缺少链路分类的失败结果。
- 扩大触屏按钮操作区域，调整表单字体以避免 Safari 聚焦时自动放大；修复下拉框、通知和监控表格在窄屏上的排版。
- 修复仪表盘、转发卡片长地址撑宽页面，系统设置保存按钮适配底部安全区，个人中心版本信息不再悬浮遮挡内容。

验证：TypeScript、生产构建及 lint；WebKit 和 Chromium 各 83 项弹窗检查，覆盖 320 / 390 / 430 / 768 / 844 / 1440px，另验证长内容滚动、页面位置恢复、横竖屏切换、下拉选择、浅色主题与监控表格。键盘缩小视口经过模拟验证，未连接实体 iPhone。
