## FLUX 3.1.0

首个个人维护版本，基于 FLVX 继续开发。

- 前端迁移到 Mantine，统一 13 个页面的布局、导航、表单、表格和弹窗。
- 支持浅色、深色、系统模式、强调色和响应式手机导航。
- 大型页面拆分展示模块，路由按需加载，生产构建启用压缩。
- README、开发及部署文档改为个人项目说明，保留上游来源和许可证。
- 版本查询指向本仓库；发布脚本固定仓库和版本，修复旧模板的上游引用问题。
- 提供带校验的 Docker 镜像包，首次安装和脚本更新可在不登录镜像仓库的情况下完成。

完整业务页面浏览器交互回归及真实多节点联调仍需进一步验证。此版本的自动检查覆盖构建、后端测试、镜像启动和登录流程。
