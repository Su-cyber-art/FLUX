# FLUX 3.2.0

面板自升级现在可以查看实际下载进度、备份与重启阶段，以及最终升级或恢复结果。

- 升级任务由独立容器执行，关闭页面或后端重启不会中断任务；刷新设置页后可恢复查看。
- 镜像来自本仓库 Release，必须通过 SHA-256 校验。页面显示实际下载字节和百分比。
- 自动识别现有安装目录和 Compose 项目，保留端口、网络、数据卷及其他部署设置。
- 切换前备份配置与 SQLite / PostgreSQL 数据库，暂时阻止业务写入。前后端健康检查通过后才报告成功，失败时恢复原镜像与数据库备份。
- 网页升级和新版终端更新脚本共享互斥锁，防止两次升级同时修改同一部署。
- 发布检查覆盖两种 Linux 架构上的实际自升级、进度持久化、校验失败拒绝、数据库恢复及自定义目录与项目名。

**首次升级：**从 3.1.x 升到此版本，请下载最新 `panel_install.sh`，在原部署目录执行并选择 `2` 更新。旧版本使用旧升级逻辑，无法显示本次升级进度。安装 3.2.0 后，可在“系统设置 → 面板升级”使用新版流程。

参考 [sub2api](https://github.com/Wei-Shaw/sub2api) 的版本检查、校验备份、操作互斥与重启确认思路，为 FLUX 的 Docker Compose 部署实现独立升级任务。
