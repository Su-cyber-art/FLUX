# FLUX 3.3.8

重新设计用户管理页。

## 用户卡片

- 头像带在线状态点，禁用与配额超额以标签标出；有效期在右上角以标签显示（长期有效、到期日期、即将过期、已过期）。
- 流量以“已用 / 上限”和进度条展示，用量达到 70% 与 90% 时依次转为警告与危险色；日 / 月配额合并为一行说明。
- 规则上限与流量重置日放在信息栏中；操作精简为权限、编辑，重置流量与删除收进“更多”菜单。
- 卡片网格按可用宽度自动排列，用户名不再被截断。

## 列表视图

- 原表格改为自适应列表：用户、流量、配额与规则、有效期、操作一行显示，窄屏自动折行。

## 页面结构

- 工具栏：搜索、卡片 / 列表切换与新增用户。
- 工具栏下方显示用户总数、正常与禁用数量，以及配额超额、即将过期或已过期的用户数。
- 无用户与搜索无结果时分别给出引导。
- 流量进度条提取为共享组件，仪表盘与用户页共用。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与演示用户，在浏览器中检查卡片与列表视图、权限对话框，覆盖浅色与深色模式、1024 / 1440 宽度与手机宽度。
