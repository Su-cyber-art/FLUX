# FLUX 3.3.1

修复面板自升级完成后点击“刷新页面”，侧栏仍显示旧版本并提示可更新的问题。原按钮只刷新页面，浏览器仍可能从旧 Service Worker 返回缓存的前端。

- 升级进度、PWA 更新提示和页面加载错误的刷新按钮共用更新流程：检查更新、等待资源下载、切换前端缓存，再刷新一次。
- 刷新期间显示加载状态，网络或安装失败后可重试；保留登录与用户设置。
- 支持升级成功和恢复原版本后的刷新，保持 PWA 更新提示与离线缓存能力。

首次从 3.3.0 或更早版本升级时，旧前端的刷新按钮尚未包含本修复。如果侧栏仍停在旧版本，请使用右下角“发现新版本”提示中的“刷新”，或强制刷新浏览器一次。

验证：TypeScript、全量 ESLint、生产构建与发布脚本检查。Chromium 使用真实生产构建、Service Worker 和 Cache Storage 复现旧问题，并验证慢速安装、只刷新一次、登录保留、更新失败重试、回滚、PWA 提示刷新、同版本刷新及无 Service Worker 的刷新流程。
