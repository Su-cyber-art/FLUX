# FLUX 3.3.6

重新设计节点管理页。

## 节点卡片

- 在线节点直接显示 CPU、内存、磁盘占用，以及实时下载 / 上传速度、连接数和运行时长；占用超过 70% 与 90% 时依次转为警告与危险色。离线节点显示“节点离线，暂无实时数据”。
- 名称、在线状态、地址与版本集中在卡片顶部，节点名不再被截成两个字；到期提醒与备注以标签形式直接显示，不必再悬停查看。
- 即将续费或已逾期的节点保留醒目边框；升级进度以进度条显示。
- 操作精简为安装、升级、编辑，回退版本、关闭到期提醒与删除收进“更多”菜单。
- 远程节点的地址、共享 ID、流量、带宽上限、占用端口与绑定明细重新排版。
- 卡片网格按可用宽度自动排列。

## 列表视图

- 原表格改为自适应列表：节点、资源占用、实时速度、操作一行显示，窄屏自动折行。
- 修复远程节点地址为空时列表视图可能报错的问题。

## 页面结构

- 本地 / 远程节点、搜索、筛选、卡片 / 列表、批量与新增节点集中在工具栏，手机上精简为图标。
- 工具栏下方显示节点总数、在线与离线数量及需要续费的节点数。
- 批量模式使用吸顶操作栏：全选、取消选择、升级、删除、完成。
- 无节点、无远程节点与筛选无结果时分别给出引导。
- 修复部分节点卡片上多出一个“0”的问题。
- 禁用状态的低调按钮保持透明背景，不再像被选中。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与模拟节点上报，在浏览器中检查卡片与列表视图、批量选择、更多菜单、远程节点空状态，覆盖浅色与深色模式、1024 / 1440 宽度与手机宽度。
