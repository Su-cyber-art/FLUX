# FLUX 3.3.7

重新设计隧道管理页。

## 链路一目了然

- 卡片以时间线展示链路：入口 → 中转 → 出口，直接显示节点名称和在线状态，多节点时显示 “+N”，悬停可查看全部节点。原先只显示 “1入口 → 0跳 → 1出口” 的数量。
- 列表视图把同样的链路横向排开，最优出口状态显示在链路下方。
- 计费方式、流量倍率与 IP 偏好合并为一行说明；隧道类型与停用状态以标签显示。

## 页面结构

- 卡片网格按可用宽度自动排列，隧道名不再被截断；操作精简为编辑、诊断，删除收进“更多”菜单。
- 列表视图改为自适应布局，窄屏自动折行，勾选行即可进入批量模式。
- 工具栏：搜索、卡片 / 列表切换、批量与新增隧道，手机上精简为图标。
- 工具栏下方显示隧道总数、隧道转发与端口转发数量及停用数量。
- 批量模式使用吸顶操作栏：全选、取消选择、重新下发、删除、完成。
- 无隧道与搜索无结果时分别给出引导。
- 拖拽排序组件不再在每次渲染时重新创建。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端、演示链路与模拟节点上报，在浏览器中检查卡片与列表视图、编辑对话框，覆盖浅色与深色模式、1024 / 1440 宽度与手机宽度。
