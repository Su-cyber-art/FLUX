# FLUX 3.3.17

安全更新：使用已修复漏洞的 Go 与 Node.js 构建，同步自上游 Sagit-chu/flvx#566。

- **CVE-2026-111943（Go `crypto/x509`）**：面板后端（版本检查、升级下载、授权验证）与节点 agent（更新下载、TLS 拨号、证书校验）都使用 Go 标准库，原 Go 1.25 工具链缺少此次修复。三个 Go 模块最低版本升至 1.26.10，CI 与发版流程改为从 `go.mod` 读取 Go 版本，后端镜像改用 `golang:1.26.10-bookworm` 构建。
- **CVE-2026-111497（Node.js Brotli）**：Node.js 只用于前端构建与 skill 发布，不在面板生产环境运行。CI 由已停止支持的 Node.js 20 改为 `.node-version` 固定的 22.23.4，前端镜像使用 `node:22.23.4-alpine`；前端开启 `engine-strict`，只接受已修复的 22.23.4+、24.22.1+、26.12.1+。
- 上游一并排查的 PHP 漏洞（CVE-2026-109618、CVE-2026-109619）与 FLUX 无关，FLUX 不包含 PHP。

**需要操作**：Go 标准库编译在二进制里，只有更新到本版本的面板与 agent 才包含修复。请升级面板，并在“节点管理”中把所有节点的 agent 升级到 3.3.17（离线节点上线后也要升级）。详见 [运行时漏洞说明](https://github.com/Su-cyber-art/FLUX/blob/main/docs/security/2026-10-runtime-updates.md)。

验证：Go 1.26.10 下 `go-backend`、`go-gost`、`go-gost/x` 的全部测试通过；交叉编译 Linux amd64/arm64 的后端与 agent，`go version` 确认均为 go1.26.10。Node.js 22.23.4、pnpm 10.28.1 下前端 `install --frozen-lockfile` 与 `build` 通过，锁文件无变化；未修复的 Node.js 26.6.0 被 `engine-strict` 拒绝。固定的两个 Docker 基础镜像标签已确认存在。
