# FLUX 3.3.21

修复服务器到期、被删除或永久离线后，节点一直停留在“待删除”的问题。

- 单个和批量删除确认框新增“仅从面板强制移除”，无需等待 agent 在线、升级或确认清理，也不会尝试 SSH 清理。
- 强制移除会删除本地节点记录、监控数据、流量批次收据和 SSH 凭据，断开现有节点连接；旧接入凭证无法再次连接面板。
- 普通删除仍等待远端清理确认，离线节点上线后自动重试。强制移除使用独立接口和管理员权限检查，不会把未执行的远端清理标记为成功。
- 强制移除意图持久化为“待移除”；数据库删除失败或面板重启后重试，仍只移除面板数据，不会变成远端卸载。
- 保留隧道、转发、联邦绑定及共享引用保护，最终删除事务再次检查关联资源。批量操作逐项报告成功和失败，失败项保留供处理。

## 升级说明

本次功能只需升级面板。服务器已经销毁、永久无法连接，或旧版 agent 无法升级时，可在节点删除确认框中勾选“仅从面板强制移除”。有关联资源时，先删除或迁移这些资源。

强制移除不会停止或卸载远端 agent，也不会清除远端监听及转发规则。若服务器仍在运行，请自行清理；普通删除继续使用原有的远端清理流程。
