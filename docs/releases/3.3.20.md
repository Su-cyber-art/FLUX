# FLUX 3.3.20

改进登录故障恢复、流量上报确认与隧道配置下发反馈。

- 用户状态查询发生数据库错误时返回 HTTP / 业务码 `503`，拒绝本次访问并保留登录凭证；恢复后可继续使用原 JWT。账号禁用、密码修改和无效令牌仍按原规则失效。
- Agent 每批最多发送 500 条流量记录，发送失败或确认响应丢失时保留原批次和序号重试，新流量留到下一批。面板在同一事务内完成批次收据、转发与用户流量、用户配额及共享流量记账，重复批次不会重复计量；事务失败不确认批次。
- 隧道配置保存后，如果关联转发下发失败、节点离线或部分运行配置被跳过，返回明确的待同步状态和失败明细，前端显示警告，避免把尚未生效的配置提示为更新成功。
- 普通用户的转发列表在数据库查询阶段按用户过滤，避免先查询并组装全部用户的记录；保留原返回字段和管理员完整列表。
- 常规 CI 增加后端完整测试、Agent 控制与运行时回归，以及不会修改源码的前端 lint。

## 升级说明

先升级面板，再升级 Agent。新版面板兼容旧 Agent 的上报格式；流量批次确认与去重需要面板和 Agent 均升级到本版本。Agent 的未确认批次保存在进程内存中，进程退出或崩溃后不会恢复，不属于持久化投递。

隧道提示待同步时，配置已经保存，请检查节点状态并重新下发；待同步不表示节点已应用配置。

## 验证

本地后端完整测试（含契约测试）、Agent 与控制协议回归、相关竞态检测，以及前端 TypeScript、生产构建、只读 ESLint 检查通过。新增回归覆盖数据库故障后原凭证恢复、流量事务回滚与同批次重试、并发去重、共享流量归属、响应丢失与地址回退、批次大小限制及隧道待同步反馈。发布流水线继续验证两种 Linux 架构的镜像、自升级和失败恢复。
