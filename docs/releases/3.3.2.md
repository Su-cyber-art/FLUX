# FLUX 3.3.2

控制台视觉统一的第一步，并重新设计仪表盘。

## 统一的语义色调

- 全站颜色改为 7 个语义色调（默认、主色、次要、成功、警告、危险、信息），浅色与深色模式自动切换，跟随所选强调色。
- 页面中的 Tailwind 原始色与手写深色覆盖全部替换为色调令牌；修复深色模式下节点续费时间等文字几乎不可见的问题。
- 徽章、按钮浅色样式的文字加深，浅色背景上更易阅读。
- 约 80 个内联 SVG 改为 lucide 图标，个人中心入口与侧栏导航使用同一组图标。

## 仪表盘

- 顶部改为三张额度卡：流量用量（已用 / 配额、进度条与重置时间）、转发规则（已用 / 配额）、账户有效期；用量达到 70% 与 90% 时进度条依次转为警告与危险色。
- 24 小时流量改为面积图，显示合计与峰值时段，数据刷新时不再重播动画。
- 管理员的节点到期提醒与流量图并排显示，按状态标注已逾期、即将到期，并可直接前往节点管理。
- 成员的隧道权限以卡片展示计费方式、有效期，以及流量和规则两项独立配额。
- 转发规则按隧道分组为紧凑列表：入口与目标地址可一键复制，多地址显示数量并可查看全部；同时列出上传、下载与计费流量。
- 加载时显示骨架屏；手机上地址改为上下排列，配额条单列显示。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与演示数据，在浏览器中检查管理员与成员视角、浅色与深色模式、桌面与手机宽度，以及多地址弹窗与复制。
