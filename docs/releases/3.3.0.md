# FLUX 3.3.0

同步 FLVX 上游至 `d930303`，纳入共享规则保护、安全通行证密钥登录、升级配置说明和无用户名密钥登录四项更新。

- 新增 Mantine 通行证密钥登录入口与个人中心密钥管理，支持绑定、查看和删除密钥，以及加载失败后的重试。
- 密钥登录与密码登录共用会话和跳转流程，按当前密码判断首次改密要求。
- 修复共享规则在下发、恢复、流量清理和节点重连时的归属及生命周期问题。
- 代理配置加载、API 与面板指令使用统一事务锁，失败重载恢复原有监听和规则；适配本 fork 的节点卸载及待清理节点恢复，避免卸载结束时等待自身退出。
- IPv4 / IPv6 部署模板支持 `FLVX_WEBAUTHN_ORIGIN`，安装文档提供新装、升级和更换域名的配置说明。

通行证密钥默认关闭。启用前需将 `FLVX_WEBAUTHN_ORIGIN` 配置为公开前端 HTTPS origin，并重建后端容器。用户先通过密码登录绑定密钥，随后即可直接选择密钥登录。

建议面板与节点代理一并更新至 3.3.0，以使用完整的共享规则恢复与代理事务保护。

验证：Go 1.25 后端与两个代理模块测试、TypeScript / lint / 生产构建、安装和升级脚本检查。Chromium 使用虚拟认证器验证密钥绑定、无用户名登录、返回原页面、列表加载重试和删除后拒绝登录，并检查桌面及 320px 手机布局。发布流程另在 Linux amd64 / arm64 验证镜像、systemd / OpenRC 卸载及 SQLite / PostgreSQL 自升级恢复。
