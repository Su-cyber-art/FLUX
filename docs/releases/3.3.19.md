# FLUX 3.3.19

去掉商业版授权，站点品牌改为自由编辑。FLUX 是个人维护的开源版本，不再需要授权码。

- “系统设置”中的“授权与品牌”改为“站点品牌”：应用名称、网页角标 Logo、浏览器图标、隐藏页面底部 “Powered by FLVX” 均可直接修改并保存，移除授权激活码输入框。
- 后端移除授权激活接口、每 12 小时联网校验授权的后台任务，以及保存与公开读取品牌配置时的授权检查；后端镜像构建不再注入授权平台账号。
- 已有面板中保存过的授权相关配置继续对外隐藏，不会通过配置接口泄露。
- 默认应用名称保持为 FLVX：新安装的默认值改为 “FLVX”，升级时未改过的旧默认值 “flux” 会自动改为 “FLVX”，界面显示与升级前一致。需要其他名称时，在“系统设置 → 站点品牌”中修改即可。

升级面板即可生效，节点无需更新。

验证：后端全部测试通过（原授权测试改为验证未授权时可保存、可公开读取品牌配置）；前端 TypeScript、ESLint、生产构建通过。使用本地后端在浏览器中修改应用名称并开启隐藏底部版权信息，保存后标签页标题与侧栏名称即时更新、底部品牌信息隐藏，未登录的公开配置接口返回新名称；旧默认值 “flux” 在面板启动后自动改为 “FLVX”。
