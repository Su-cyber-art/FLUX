# FLUX 3.3.9

重新设计分组权限页与限速策略页。

## 分组权限

- 隧道分组与用户分组并排显示（窄屏上下排列），每个分组列出成员标签，超过 4 个时显示 “+N” 并可悬停查看全部；停用分组以标签标出。
- 权限分配改为一句话式的授权栏：“用户分组 可使用 隧道分组”，未选完整时授权按钮不可用；授权记录以 “用户分组 → 隧道分组” 展示。
- 删除分组和回收权限现在需要二次确认，避免误操作（此前点击即生效）。
- 各区域无数据时显示空状态说明。

## 限速策略

- 卡片以大号数字显示带宽上限，并换算为 MB/s；停用策略以标签标出。
- 列表视图改为紧凑行，操作统一为编辑与删除图标。
- 工具栏、统计栏与空状态与其他页面保持一致。

## 其他

- 区块标题与确认对话框提取为共享组件。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与演示分组、限速数据，在浏览器中检查两页的布局、删除确认与取消，覆盖浅色与深色模式、1024 / 1440 宽度与手机宽度。
