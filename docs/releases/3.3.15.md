# FLUX 3.3.15

收尾面板美化：次要弹窗与监控详情页。

- 用户“隧道权限”弹窗分为“监控权限 / 分配新权限 / 已有权限”三段；已有权限从 9 列表格改为带流量进度条的列表，修复原表头多出“最大连接”一列、导致其后各列错位的问题。
- 用户页的删除用户、移除隧道权限、重置账号流量、重置隧道流量确认框改用统一的小号确认对话框，重置类操作以警示色按钮确认，并以三栏展示上行 / 下行 / 合计流量；编辑隧道权限弹窗补充标题说明。
- 批量操作结果弹窗直接列出每个失败项及原因，无需逐个展开；复制按钮带图标。
- 规则与隧道诊断弹窗宽度从 1180px 收窄到 800px，诊断进行中显示统一的进度条，无数据时使用标准空状态。
- 节点安装命令改为“三步说明 + 终端风格命令块”，点击命令即可全选，去掉表情符号提示。
- 节点监控详情：返回按钮与标题栏重做；实时指标卡片左对齐，CPU / 内存 / 磁盘附带用量条；“节点指标”“服务监控”使用统一分区标题，指标类型改为分段切换，服务监控切换改为带状态点的胶囊按钮，空状态统一样式；时间范围选择不再出现无意义的清除按钮。
- 隧道监控详情：同样的标题栏与指标卡片样式，“全链路拓扑”“质量趋势”“流量趋势”使用统一分区标题与刷新按钮。
- 通知新增警示样式，替换原先以表情符号作为图标的提示；清理剩余的 `dark:` 颜色覆盖，统一改用语义色。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与模拟节点在浏览器中检查隧道权限弹窗与重置确认、安装命令弹窗、规则诊断进度、节点与隧道监控详情，覆盖浅色与深色模式、1440 宽度与手机宽度。批量操作结果弹窗与警示通知未在浏览器中实际触发，仅通过类型检查与构建验证。
