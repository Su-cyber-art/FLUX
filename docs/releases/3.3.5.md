# FLUX 3.3.5

重新设计转发规则页。

## 列表视图

- 原先最小宽度 1320px 的表格改为自适应的规则列表：名称与策略、入口 → 目标、流量、运行开关、操作在一行内显示，常见笔记本宽度下不再需要横向滚动。
- 列表宽度不足时自动折为两到三行：规则名独占一行，地址换行显示，流量与操作并排；手机上同样适用。
- 入口与目标地址显示为可复制的地址标签，多地址显示数量并可查看全部；流量列同时给出总量与上下行明细。
- 编辑、诊断直接显示为图标按钮，流量清零和删除收进“更多”菜单，删除仍需二次确认。

## 卡片视图

- 卡片网格按可用宽度自动排列，规则名不再被截成一两个字。
- 卡片展示运行状态、负载策略、入口与目标地址、流量明细，操作按钮改为统一的图标样式。

## 页面结构

- 工具栏：搜索、带条件数量的“筛选”、列表 / 卡片切换、“导入 / 导出”菜单与“新增规则”。
- 工具栏下方显示规则总数、运行中与未运行数量、累计流量，筛选时注明全部数量。
- 勾选规则后出现吸顶的批量操作栏：启用、暂停、重新下发、更换隧道、删除。
- 用户与隧道分组标题重新设计：隧道倍率仅在不为 1x 时显示，分组仍可折叠和拖拽排序。
- 无规则与筛选无结果时分别给出引导，可直接新增规则或清空筛选条件。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与演示数据，在浏览器中检查列表与卡片视图、紧凑模式、勾选与批量栏、更多菜单与删除确认，覆盖浅色与深色模式、1024 / 1440 宽度与手机宽度。
