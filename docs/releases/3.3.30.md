# FLUX 3.3.30

前端界面重构为平铺式运维控制台（Console UI），并摘取上游端口原子预留、PostgreSQL 中继认证及备份恢复序列修复。

## 控制台界面重构

页面功能、路由与操作流程保持不变，重做整体版式与信息密度：

- **贴边侧栏与粘性顶栏**：取消浮空双圆角托盘与外层套娃卡片，改为贴边侧栏、52px 粘性顶栏（面包屑位置、⌘K 搜索、深浅色切换、账号菜单）与平铺画布。
- **高密度列表与卡片**：
  - **转发规则**：取消按用户与隧道多层套卡片的结构，改为轻量分组标题配自适应多列卡片或对齐数据表；地址统一使用等宽字体与悬停复制。
  - **节点、隧道、用户、分组、限速与面板共享**：卡片重排为三列紧凑网格，列表对齐为标准数据表；状态指示统一改为圆点加文字，配额与负载改为平滑细进度条。
  - **仪表盘与运行监控**：顶部改为三栏一体式指标条，规则与隧道权限改为紧凑行列表，精简无数据时的空白占位。
  - **系统设置、个人中心与登录页**：桌面端设置页改为左侧固定分区导航配单列设置卡；登录与修改密码页简化为微网格背景加居中单卡片。
- **样式结构拆分**：原单文件 `application.css` 按区域拆分为 `shell.css`、`components.css`、`diagnosis.css`、`pages/*.css` 与 `responsive.css`。

## 后端功能与修复

摘取上游 `Sagit-chu/flvx` 的核心可靠性更新（`#576`、`#579`、`#584`）：

- **原子端口预留与顺次分配入口端口**：将端口选取与占用写入纳入跨 SQLite / PostgreSQL 的串行事务锁，消除并发创建规则或迁移隧道时的端口冲突竞态；“系统设置 → 访问与安全”新增**顺次分配入口端口**开关（开启后按从小到大分配首个空闲端口，关闭保持随机）。
- **PostgreSQL 中继隧道认证查询修复**：修正查询 `chain_tunnel.chain_type` 时的文本参数绑定，修复 PostgreSQL 面板新建或校验中继隧道凭据时的类型不匹配报错。
- **转发规则用户名实时关联**：修改用户名后，转发规则列表动态显示最新归属用户名，不再停留在创建时的旧名称快照。
- **PostgreSQL 备份导入序列修复**：带显式 ID 导入备份数据时，在导入事务内加锁并自动推进各表自增序列，避免导入后新建记录触发主键冲突。
