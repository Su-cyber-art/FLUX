# FLUX 3.3.12

重做系统设置页与个人中心。

- 系统设置改为分区布局：左侧导航（手机上为顶部横向标签）对应访问与安全、外观、监控、更新与升级、授权与品牌、公告、数据备份七个分区，滚动时自动高亮当前分区，点击可平滑跳转。
- 每个设置项改为“说明在左、控件在右”的统一行样式，窄屏自动上下排列。
- 有未保存修改时，底部出现固定保存栏，可“放弃修改”或“保存配置”；移除旧的浮动保存按钮。
- 背景壁纸改为三张预览卡片（默认、浅色模式、深色模式），直接显示图片、纯色或自适应背景效果；去掉表情符号标题，清除操作改为图标按钮。
- 外观设置（显示模式、强调色）并入设置行样式。
- 个人中心改为账户卡片 + 分区：账号安全（修改用户名与密码、通行证密钥）、外观偏好（所有用户都可设置显示模式和强调色）、管理入口（仅管理员）。
- 通行证密钥改为设置行样式，已绑定密钥以列表展示，删除改为图标按钮。
- 修改凭据弹窗收窄，补充说明“保存后需要重新登录”，并为输入框加上浏览器自动填充提示。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端（开启 WebAuthn）在浏览器中检查保存栏、放弃修改、分区跳转与高亮、壁纸卡片、通行证密钥与修改凭据弹窗，覆盖浅色与深色模式、1440 宽度与手机宽度。
