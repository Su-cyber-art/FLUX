# FLUX 3.3.11

打磨运行监控页。

- 顶部新增“在线节点”统计卡（在线 / 总数，并提示离线数量），与平均 CPU、活跃连接、实时带宽并列；窄屏两列显示，手机上不再占满整屏。
- 节点列表去掉独立的状态列，状态点与系统图标并入节点名称，名称下方显示运行时长或离线；速率、累计流量、连接数改为紧凑的两行，CPU / 内存 / 磁盘使用统一宽度的进度条，常见宽度下不再出现横向滚动条。
- 显示方式改为卡片 / 列表分段切换，与其他页面一致；刷新按钮带图标，手机上精简为图标。
- 节点监控 / 隧道监控切换在手机上保持单行。

验证：TypeScript、全量 ESLint、生产构建。使用本地后端与模拟节点上报，在浏览器中检查列表、卡片、节点详情与隧道监控，覆盖浅色与深色模式、1440 宽度与手机宽度。
