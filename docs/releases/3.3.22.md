# FLUX 3.3.22

控制台视觉与动效全面升级：更有层次的材质、统一的过渡动画，以及重新设计的登录页。

- 材质与层次：重新调校浅色 / 深色中性色，深色模式更深、层级更分明；新增三档柔和阴影（卡片静止、悬停浮起、弹窗与菜单）。顶栏、批量操作栏、设置保存栏和通知改为毛玻璃，页面背景加入随强调色变化的环境光晕；设置自定义壁纸时自动关闭光晕。
- 统一动效：页面切换淡入，卡片依次上浮出现；弹窗、菜单、下拉框与提示框改为弹出动画，弹窗背景模糊；按钮按压微缩、主按钮带同色光晕，输入框聚焦显示主色光环，开关滑块轻弹；侧栏收起 / 展开平滑过渡，当前导航项带弹性指示条。
- 深浅色切换：支持 View Transitions 的浏览器会从点击位置以圆形展开新配色；不支持的浏览器或开启“减少动态效果”时直接切换。
- 登录页：缓慢漂动的极光背景、毛玻璃登录卡片、渐变标题，链路示意中的隧道节点呼吸发光。
- 仪表盘：统计卡片角落带对应色调的光晕，悬停时卡片浮起；流量曲线发光描边，悬停提示框改为毛玻璃；进度条首次加载时从零填充，骨架屏改为扫光效果。
- 强调色由 3 种增加到 5 种，新增“靛青”和“葡萄紫”；已保存的偏好保持不变。

## 升级说明

本次只涉及前端，升级面板即可，Agent 无需升级，接口与数据无变化。所有动画在系统开启“减少动态效果”时自动关闭。

## 验证

前端 TypeScript、生产构建和 ESLint 检查通过。使用真实后端和演示数据，在无头浏览器中逐页对比浅色 / 深色、桌面 / 手机布局，并检查登录、仪表盘、转发、节点、设置、新增规则弹窗、账户菜单、快速访问和移动端导航，以及深浅色切换动画。发布流水线继续验证两种 Linux 架构的镜像、自升级和失败恢复。
