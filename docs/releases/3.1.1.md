# FLUX 3.1.1

修复首次登录反复要求改密的问题，补齐 Docker 自动安装和节点彻底清理流程。

- 首次设置成功后重新登录进入控制台；保留默认用户名不再触发改密循环。默认密码不能被再次设为新密码，旧会话立即失效。
- 一键部署检测不到 Docker 时先询问，确认后使用 `https://get.docker.com` 官方脚本安装。引擎、Compose 和 `hello-world` 全部验证通过后才继续部署；已有 Docker 不会被自动升级。
- 删除本地节点会让 agent 停止转发，清除配置、密钥、二进制及升级备份，禁用并移除 systemd / OpenRC 服务。面板收到清理确认后才删除记录，清理失败不会假报成功。
- 离线删除请求持久保存，节点重新上线后继续清理；批量删除返回各项失败原因。
- 删除前需解除关联隧道、转发和共享。远程共享节点只移除本面板接入；nftables 节点先清理规则再删除 SSH 配置。

**升级说明：**面板与节点 agent 都需升级到此版本，才能使用完整 agent 卸载功能。使用官方安装目录 `/etc/flux_agent`，或可确认归属的旧版 `/etc/gost`；自定义目录不会被递归删除。
