# FLUX 3.3.24

前端整体重构：移除旧的组件兼容层，统一各列表页的交互和视觉，并把超大页面拆分为独立组件。功能和接口不变。

## 界面调整

- **统一工具栏**：转发、隧道、节点、用户、限速、面板共享六个页面使用同一套工具栏。左侧为标签、搜索、筛选，右侧为视图切换、其他操作和主按钮，视图切换统一为“卡片”在前。存在筛选条件时显示“清空条件”。手机上只显示图标的按钮居中显示。
- **页面标题不再重复**：顶栏面包屑平时显示“控制台 › 分组”，页面大标题滚出视野后才淡入当前页名。
- **统一空状态**：转发规则页的空状态与其他页面一致；“没有匹配结果”使用灰色图标，“还没有数据”使用主色图标。
- **应用内确认弹窗**：转发规则强制删除、删除服务监控项，不再弹出浏览器原生确认框。强制删除的确认会显示后端返回的失败原因，并叠在删除弹窗之上。
- **图表配色跟随主题**：节点监控、隧道监控的折线颜色改为主题色，暗色模式下自动调亮；提示框改为与界面一致的半透明样式，不再固定为黑色。
- **诊断弹窗合并**：规则诊断与隧道诊断共用一个弹窗组件，表现一致。
- **侧栏滚动条**：仅在滚动时出现。
- **下拉选项显示修复**：部分下拉框（如节点续费周期）此前显示内部取值，现在显示对应的中文名称。

## 代码结构

- 删除 `components/ui/` 下 17 个仿 HeroUI 接口的包装组件，调用处直接使用 Mantine，默认样式统一放在主题配置中。移除未使用的依赖 `@internationalized/date`。
- 拆分超大页面：转发 4387→2785 行、隧道 3129→1467 行、节点 2756→1797 行、监控视图 2206→1036 行、系统设置 2099→1508 行、用户 1744→1185 行。20 个弹窗拆为独立组件，诊断、导入、导出逻辑提取为 hook。

## 升级说明

本次只涉及前端，升级面板即可，Agent 无需升级，接口与数据无变化。

## 验证

前端 TypeScript、ESLint、生产构建均通过，锁文件通过 `--frozen-lockfile` 校验。用无头浏览器截取 11 个页面及新增弹窗的桌面端和移动端截图，与重构前逐像素对比，除上述有意调整外无其他差异。另外在模拟接口下跑了 24 项交互测试，均通过、控制台无报错，覆盖：

- 新建规则提交的数据
- 启停开关
- 筛选
- 各类下拉、多选、单选、日期选择
- 规则与隧道诊断弹窗
- 导入导出
- 强制删除确认
- 监控项删除的取消与确认
