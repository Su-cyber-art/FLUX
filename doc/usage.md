# 使用指南

## 建立第一条转发规则

1. 在 **节点管理** 中添加节点，配置地址、可用端口和接入信息，再启动对应代理。
2. 确认节点在线后，在 **隧道管理** 中配置入口、出口及可选中继。
3. 在 **转发规则** 中选择隧道，填写入口端口、目标地址与策略。
4. 保存后检查下发结果，使用诊断功能查看链路状态。

新增、编辑、批量下发的结果以页面返回的状态和错误详情为准。多入口隧道、自定义监听地址和端口范围之间存在关联约束，表单会按当前节点和隧道配置限制可选项。

## 页面与用途

| 页面 | 主要用途 |
| --- | --- |
| 仪表盘 | 查看自身流量配额、隧道权限、规则摘要、公告和到期提醒 |
| 转发规则 | 搜索与筛选、列表/卡片、分组、排序、批量启停/下发、导入导出与诊断 |
| 隧道管理 | 配置拓扑、流量策略、出口选择及关联规则处理 |
| 节点管理 | 区分本地/远程节点，管理安装、状态、到期信息和版本 |
| 运行监控 | 查看节点资源、服务探测、隧道质量与历史趋势 |
| 用户管理 | 账号状态、流量/数量配额、隧道授权与监控权限 |
| 分组权限 | 用户组、隧道组及组间授权 |
| 限速策略 | 可复用的带宽限制 |
| 面板共享 | 分享本地资源，接入远程节点 |
| 系统设置 | 全局配置、外观、公告、备份及版本信息 |
| 个人中心 | 账号信息和密码修改 |

普通用户仅能使用获得授权的功能；监控权限独立管理。后端会验证所有操作权限。

## 界面操作

- 侧栏按工作空间、网络服务和管理功能分组；手机通过顶部菜单打开同一组导航。
- 顶部支持页面搜索、深浅色切换和账号菜单。
- 外观支持浅色、深色、跟随系统及强调色，偏好保存在当前浏览器。
- 大型表单在手机上使用全屏对话框；确认类对话框保持紧凑。
- 表格、卡片、批量选择、排序和筛选偏好按对应页面的规则保留。

## 配额与备份

流量配额支持多种单位，具体单位及计费方向以表单和隧道配置为准。重置流量与删除规则是不同操作。

系统设置中的备份用于导出选定业务配置。迁移前核对选项；需要完整保留数据库和监控历史时，另做数据库级备份。
